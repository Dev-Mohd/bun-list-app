# خريطة البيانات (C00، مبدئية)

المطلوب في المرجع (قسم PDPL): الغرض والمزود وموقع المعالجة والتخزين والنسخ الاحتياطية والاحتفاظ والأساس النظامي ومسؤول المراجعة. هذه خريطة تصميم وليست إعلان امتثال.

## النسخة الحالية (C01) — على الجهاز فقط

| البيانات | الغرض | الموقع | الاحتفاظ |
|---|---|---|---|
| معرف زائر عشوائي (UUID) | فصل بيانات الزائر عن أي حساب لاحق | SwiftData داخل حاوية التطبيق | حتى حذف التطبيق، أو ضم ناجح (C04) |
| سجلات المجموعة (الدفعة، الحالات، الملاحظة، التواريخ) | مجموعتي | SwiftData | كذلك؛ الإزالة تُبقي التاريخ لمنع تكرار المكافأة |
| أحداث أول جمع ونقل الموسم والعمليات | منع التكرار وإقرار الكيس | SwiftData | كذلك |
| صورة الكاميرا أو المختارة | استخراج تجريبي | الذاكرة فقط | لا تُحفظ ولا تُرسل في C01 |

لا خادم ولا مزود خارجي ولا تحليلات ولا موقع جغرافي في C01. النسخ الاحتياطي يتبع إعداد iCloud/النسخ في جهاز المستخدم ولم يُستبعد صراحة؛ قرار مفتوح قبل C04.

## غير متحقق — قبل C03/C04/C05

| البند | الحالة |
|---|---|
| موقع Supabase/قاعدة PostgreSQL الحالية | غير متحقق؛ لا نفترضه داخل المملكة أو خارجها |
| مزود قراءة الصور وموقع معالجته واحتفاظه | لم يُختر |
| النسخ الاحتياطية للخادم والسجلات | غير محدد |
| الأساس النظامي ومسؤول المراجعة | لم يُعيّن |
| ضمانات النقل خارج المملكة | تُراجع مع البنود القياسية حيث تنطبق |

جداول الاحتفاظ المقترحة لصور الدليل (90/30/7 يومًا) في المرجع، وتُفعل مع C05 بعد مراجعة مسؤول البيانات.
