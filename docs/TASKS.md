المرجع: [`docs/spec/BunnList-Master-Spec-v2.3.md`](spec/BunnList-Master-Spec-v2.3.md). آخر تحديث: 21 أكتوبر 2026.

## البوابات

كل بوابة تُسجَّل وحدها. نجاح Core على Linux لا يعني نجاح بناء Apple.

| البوابة | الحالة | الدليل |
|---|---|---|
| Linux — اختبارات BunnListCore | **ناجحة** | `swift test`: 49 اختبارًا، صفر إخفاق، صفر تحذيرات بناء (Swift 6.0.3) — [VALIDATION.md](VALIDATION.md) |
| Linux — توليد project.yml (فحص إضافي) | **ناجح** | XcodeGen 2.42.0 مبني من المصدر على Linux ولّد المشروع في نسخة مؤقتة: 3 أهداف ومخطط مشترك؛ ليس بديلًا عن التوليد على Mac |
| Mac/المحاكي — توليد وبناء واختبار | **معلقة** | لا يوجد Mac. الأوامر في [mac-verification.md](mac-verification.md). مطلوبة لإغلاق C00 وC01 |
| CAM-DEVICE — كاميرا فعلية على آيفون | **معلقة** | صاحب المشروع بحسابه. شرط C05، لا يمنع إغلاق C01 |
| الإنتاج | **لم يُلمس** | لا ترحيل ولا نشر ولا اتصال بقاعدة |
