# قرارات التنفيذ

- المستودع المحدد `Dev-Mohd/bun-list-app` كان فارغًا بلا التزامات أو فروع منشورة عند البدء. بموافقة المستخدم أُنشئ التطبيق في جذره، دون استنساخ `Dev-Mohd/bunnlist` المذكور في الوثيقة المرجعية، ودون تغيير أي تطبيق موقع.
- iOS 17 حد أدنى مبدئي لاستخدام واجهات SwiftUI الحديثة مثل تغيّر الحالة وContentUnavailableView؛ Swift language mode 5 وSwift tools 5.9 يسمحان باستخدام Xcode 15+. بناء Apple SDK غير متاح في بيئة Linux الحالية.
- `Core` مستقل عن SwiftUI؛ واجهة `StatePersistence` تفصل الحفظ عن قواعد العمل. التخزين ملف JSON بإصدار معلوم وكتابة ذرية بدل SwiftData، لتشغيل اختبارات الاستعادة وقواعد البيانات نفسها على Linux دون اعتماديات خارجية.
- `AppStore` يحدّث لقطة الواجهة بعد نجاح كتابة المستودع. عمليات النسخة الصغيرة متزامنة على main actor، ومناسبة لحجم البيانات التجريبي فقط. قبل بيانات كبيرة يلزم نقل القراءة والكتابة إلى actor خلفي مع الحفاظ على تسلسل المعاملات.
- معرف المسودة ثابت، ويصبح معرف التجربة الجديدة؛ إرسال المسودة المنشورة مرتين لا ينشئ منشورًا ثانيًا. التعديل يحتفظ بمعرف المنشور وتاريخ إنشائه. حذف الأصل لا يحذف التجارب المشتقة منه.
- المسودة تحفظ نصوص القيم كما أدخلت، حتى لو كانت غير صالحة للنشر. النشر يتحقق من القيم الموجبة ومحددات الطريقة، مع قبول الأرقام العربية والفاصل العشري العربي. القيم غير المتوفرة تبقى nil.
- صفحات الأشخاص تُظهر بيانات العرض والتجارب والتقييمات فقط. المستخدم المحلي ثابت وموسوم بوضوح؛ لا جلسة أو تسجيل دخول مصطنع.
- التنقل الخماسي في الوثيقة مقدم على الملصق الذي يعرض أربعة عناصر. الملصق مرجع مزاج بصري، وليس واجهة منسوخة.
- الألوان الدلالية مشتقة من المرجع مع تعديل درجات الزيتوني والذهبي لقراءة أوضح على الخلفيات الفاتحة، وبدائل داكنة. تعتمد النصوص خط النظام ولا تستخدم أحجامًا ثابتة؛ الأيقونة الزخرفية للحساب وحدها بحجم ثابت.
- اعتمد اسم جهة المطور `devmohd` من رد المستخدم؛ المعرّف `dev.devmohd.bunnlist` ولا يفترض ملكية نطاق أو فريق توقيع Apple.
- أصل الشعار وأيقونة التطبيق غير مضمّنين لغياب الملف القابل للقراءة. لا يتضمن التسليم شعارًا معاد الرسم. توضّح الواجهة هذا النقص.
