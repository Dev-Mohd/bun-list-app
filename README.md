# بن لست · BunnList

تطبيق آيفون أصلي باستخدام SwiftUI لاكتشاف محاصيل القهوة المنزلية وتسجيل تجارب تحضيرها. **هذه نسخة تجريبية محلية: لا تسجيل دخول، لا خادم، ولا نشر على الإنترنت.** الأسماء والمحاصيل والمحمصات الثلاثة بيانات توضيحية.

## التشغيل على الآيفون والمحاكي

- يتطلب macOS وXcode 15 أو أحدث مع iOS SDK ومحاكي iOS 17 أو أحدث. الهدف الأدنى iOS 17، والجهاز المستهدف iPhone.
- افتح `BunnList.xcodeproj`، واختر مخطط `BunnList` ومحاكي آيفون متاحًا، ثم Run. لا تحتاج إلى حساب مطور مدفوع للمحاكي.
- معرّف التطبيق `dev.devmohd.bunnlist`. لتشغيله على جهاز فعلي، اختر فريق التوقيع الخاص بك في Signing & Capabilities.
- الواجهة عربية واتجاهها من اليمين لليسار، بخط النظام وDynamic Type وألوان دلالية للوضعين الفاتح والداكن.

```sh
xcodebuild -list -project BunnList.xcodeproj
xcodebuild -showdestinations -project BunnList.xcodeproj -scheme BunnList
# استبدل SIMULATOR_UDID بمعرف وجهة متاحة من الأمر السابق.
xcodebuild -project BunnList.xcodeproj -scheme BunnList \
  -destination 'platform=iOS Simulator,id=SIMULATOR_UDID' \
  -derivedDataPath DerivedData CODE_SIGNING_ALLOWED=NO build
xcodebuild -project BunnList.xcodeproj -scheme BunnList \
  -destination 'platform=iOS Simulator,id=SIMULATOR_UDID' \
  -derivedDataPath DerivedData CODE_SIGNING_ALLOWED=NO test
```

المخطط المشترك يتضمن اختبارات المنطق `BunnListTests` واختبار الواجهة `BunnListUITests`. استخدم محاكي اختبار مخصصًا؛ اختبار الواجهة ينشئ تجربة وقد يستبدل مسودة سابقة بعد تأكيد الحوار آليًا. لا تشغّله على بيانات مهمة. لا تحذف الاختبارات بيانات التطبيق عند إعادة الإطلاق.

## اختبارات المنطق على Linux أو macOS

```sh
bash scripts/test-core.sh
```

يستخدم Swift المثبت إن وجد، أو Docker وصورة Swift 6.0.3 الرسمية المثبتة بالـ digest. لا توجد اعتماديات Swift خارجية. `Package.swift` يضم طبقة `Core` فقط؛ نجاح `swift test` لا يعني نجاح بناء واجهة SwiftUI أو مشروع iOS.

## الشعار الأصلي

الصورة ظاهرة في المحادثة، لكن لم يتوفر ملفها الأصلي للتنزيل ضمن المرفقات المتاحة. لم يُعد رسمها أو تغيير نسبها. مجموعة `BunnListSymbol` فارغة عمدًا، وتوضح الشاشة الرئيسية أن الأصل غير مضمّن بعد، مع رمز نظام تنبيهي منفصل وليس شعارًا بديلًا.

لإتمام الهوية، أضف **ملف** `bunnlist_symbol_transparent.png` الأصلي إلى مجموعة `BunnListSymbol` داخل Assets في Xcode (Universal / Single Scale). احتفظ بالشفافية والنسب؛ العرض يستخدم `scaledToFit`. لا تستخدم الملصق الدعائي لاستخراج شعار بديل. أيقونة التطبيق المخصصة مؤجلة أيضًا؛ هذه النسخة ليست جاهزة للتوزيع على المتجر.

## المسار المنفذ

الرئيسية ← اكتشف بالاسم أو المحمصة ← صفحة المحصول ← إضافة تجربة ← اختيار الطريقة والنجوم ← نشر محلي ← ظهور التجربة في الرئيسية والتفاصيل وحسابي. الشريط السفلي: الرئيسية، اكتشف، إضافة تجربة، مكتبتي، حسابي. الإضافة تفتح نموذجًا فوق الوجهة الحالية، و«حفظ وإغلاق» يعيدك إليها دون فقد المسودة.

- كل تجربة كيان مستقل؛ تكرار الوصفة ينسخ المحصول والطريقة والمعلمات فقط إلى مسودة جديدة بلا نجوم أو ملاحظة.
- تقييم المحصول مستقل، بصوت واحد لكل مستخدم ومحصول. تعديله لا يضيف صوتًا ثانيًا، ونشر التجارب أو حذفها لا يغيّر متوسطه.
- المفضلة وودي أجرب مستقلتان؛ جربتها مشتقة من التجارب. يمكن فتح التجارب السابقة من مكتبتك.
- التعديل والحذف متاحان لصاحب التجربة المحلي فقط، مع تحقق في طبقة البيانات أيضًا.
- الرجوع يحفظ المسودة؛ السحب لإغلاق النموذج معطّل لمنع فقد المدخلات عند فشل الكتابة. إذا توجد مسودة، يُطلب اختيار صريح قبل استبدالها.
- الصورة غير متاحة حاليًا؛ لا يوجد زر رفع لا يعمل.

## الحفظ وحدود المرحلة

تُحفظ البيانات في `Application Support/BunnList/state-v1.json` داخل حاوية التطبيق. كل كتابة ذرية؛ لا يُعلن نجاح العملية قبل نجاح الحفظ. لا يمسح فشل القراءة أو إصدار غير مدعوم الملف الأصلي. الرسالة تسمح بإعادة المحاولة؛ لا توجد إعادة ضبط صامتة. على iOS تُستخدم حماية الملف حتى أول فتح للجهاز بعد إعادة التشغيل.

الملف ليس قاعدة إنتاج ولا يدعم المزامنة أو الكتابة المتزامنة من عدة عمليات. حذْف التطبيق يحذف البيانات المحلية. لم تُنفذ الحسابات الحقيقية، API، الصور، الإبلاغ والحظر وحذف الحساب أو مزامنة التعارضات. لم يُعدّل مستودع موقع آخر أو مخطط إنتاج، ولم تُرفع تغييرات إلى GitHub أو المتجر.

راجع [سجل التحقق](docs/VALIDATION.md) و[قرارات التنفيذ](docs/DECISIONS.md) قبل اعتبار النسخة مبنية أو مجرّبة على آيفون.
